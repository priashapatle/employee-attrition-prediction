
# Employee Attrition Prediction

## 📌 Project Overview
This project predicts whether an employee is likely to leave a company using Machine Learning classification techniques.

## 📊 Dataset
- IBM HR Analytics Employee Attrition Dataset (Kaggle)

## 🧠 Machine Learning Model
- Random Forest Classifier
- Feature Encoding using One-Hot Encoding
- Model trained on 47 features

## 🛠️ Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Streamlit
- Cloudflare Tunnel (Deployment)

## 🚀 How to Run
```bash
pip install -r requirements.txt
streamlit run app.py

📈 Features
Age
Monthly Income
Job Level
Overtime

🎯 Output
Predicts whether employee will Leave or Stay
